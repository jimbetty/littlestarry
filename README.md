# littlestarry

夜星河的个人网站：AI 作品展示 + 博客。线上地址 https://littlestarry.com

## 技术栈
- [Astro](https://astro.build) 静态站点，View Transitions 无刷新切页
- [GSAP](https://gsap.com) 入场动画
- GitHub Actions 自动部署到 GitHub Pages

## 本地开发
```bash
npm install
npm run dev
```

## 写内容
- 博客：`src/content/blog/*.md`
- 作品：`src/content/works/*.md`，可玩的 demo 放 `public/play/<名字>/`
