## 关于这个作品

一条中轴线从前往后：前广场 → 山门（歇山顶、三拱门、石狮）→ 放生池与石拱桥 → 钟楼 / 鼓楼 → 主庭院 → 东西配殿 → 汉白玉三层台基上的重檐庑殿大殿 → 后院七层宝塔。围墙、柏树、银杏和花树环绕。

## 怎么玩

左键旋转，右键平移，滚轮缩放。底栏切换时辰（晨 / 午 / 昏 / 夜）和视角（全景 / 正面 / 大殿 / 宝塔 / 俯瞰），也可以打开环绕。

## 技术

200×100×260 的体素世界，只生成暴露面并加顶点 AO；屋顶由程序生成，庑殿、歇山、攒尖、飞檐翘角和重檐都能组合，斗拱、额枋、隔扇、须弥座也逐一搭出来。
